# The library source list, and the single source of truth for it.
#
# Read by BOTH builds -- cpp/Makefile via $(shell) and cpp/CMakeLists.txt via
# file(STRINGS) -- so that adding a translation unit is one edit rather than two
# that can drift. Two independently maintained file lists is exactly how a
# module ends up compiled on Linux and missing from the Windows binary, and the
# symptom (a link error on one platform only) reads as a toolchain problem
# rather than as the bookkeeping mistake it is.
#
# Blank lines and lines whose first non-space character is '#' are ignored.
# Paths are relative to this file's directory and use forward slashes on every
# platform; CMake and GNU make both accept that on Windows.
#
# DELIBERATELY ABSENT: src/platform_posix.cpp and src/platform_win32.cpp. They
# are selected by the build, not by this list -- exactly one of the two is
# compiled into any binary, and listing both here would break the invariant
# that everything named in this file is compiled unconditionally.
#
# Also absent: src/main.cpp. It is the executable entry point, not library code,
# and the test binary must not link it -- Catch2 supplies its own main().
#
# scripts/assert-sources-agree.sh checks that both builds resolve the same set.
